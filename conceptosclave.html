Conceptos clave

El vocabulario base para entender cómo un sistema automatizado mide, decide y actúa: de la variable de proceso al control PID.

Alumna: Sánchez Rodríguez Bárbara Raquel
Especialidad: Inteligencia Artificial
01 — INTRODUCCIÓN

Por qué importa este vocabulario

Antes de diseñar cualquier sistema automatizado, conviene hablar el mismo idioma.

La automatización de procesos consiste en usar tecnologías, dispositivos y sistemas de control para ejecutar tareas de forma automática, reduciendo la intervención humana directa y haciendo que el proceso sea más eficiente, repetible y preciso.

Ya sea en un entorno industrial —líneas de producción, bandas transportadoras, hornos— o en servicios —riego, control de acceso, monitoreo ambiental—, existe un conjunto de términos que se repiten una y otra vez al describir cómo funciona el sistema. Conocerlos permite leer un diagrama, entender una hoja de datos o discutir un proyecto con precisión.

Idea principal: un sistema automatizado recibe información del entorno mediante sensores, la procesa mediante un controlador, y genera una acción física mediante un actuador.
02 — ESTRUCTURA

El ciclo medir – decidir – actuar

La secuencia que se repite dentro de cualquier sistema automatizado.

01

🌡️ Sensor

Detecta una condición física del entorno y la convierte en una señal legible.

02

🧠 Controlador

Compara la lectura contra la consigna y decide qué acción tomar.

03

⚙️ Actuador

Ejecuta físicamente la corrección: enciende, mueve, abre o cierra algo.

04

📊 Proceso

La variable cambia como resultado de la acción, y el ciclo vuelve a empezar.

Característica Lazo abierto Lazo cerrado
Realimentación No existe: la salida no se vuelve a medir. Sí: la salida se mide y se usa para ajustar la siguiente acción.
Ejemplo Temporizador de riego que abre la válvula 10 minutos, sin medir la humedad real. Válvula que se abre hasta que el sensor de humedad indica el nivel deseado.
Precisión Baja; no corrige si las condiciones cambian. Alta; se ajusta continuamente al proceso real.
03 — VOCABULARIO

Conceptos clave

Los términos que aparecen una y otra vez al diseñar o describir un sistema automatizado.

01

Variable de proceso

La magnitud física que se quiere controlar: temperatura, nivel, velocidad, humedad o posición.

02

Sensor / transductor

Convierte una magnitud física en una señal eléctrica que el controlador puede leer.

03

Actuador

Ejecuta la acción física: motores, electroválvulas, relés, servos o resistencias de calefacción.

04

Controlador

Toma la decisión: desde un microcontrolador como Arduino hasta un PLC industrial.

05

Consigna (setpoint)

El valor deseado de la variable de proceso, contra el que se compara la lectura real.

06

Lazo abierto vs. cerrado

En lazo abierto no hay realimentación; en lazo cerrado la salida corrige la siguiente acción.

07

Control PID

Estrategia que combina el error proporcional, integral y derivativo para corregir con precisión y suavidad.

08

PLC

Controlador lógico programable, diseñado para operar de forma robusta en entornos industriales.

09

SCADA

Sistema de supervisión, control y adquisición de datos que centraliza la vista de varios procesos.

10

Microcontrolador

Circuito programable capaz de recibir información, procesarla y controlar otros dispositivos.

11

Conectividad

Comunicación entre dispositivos para compartir información y permitir monitoreo o control remoto.

12

Dato / telemetría

Información capturada por sensores que se transmite y analiza para tomar decisiones o generar históricos.

04 — CONTEXTO

Dónde se aplican estos conceptos

El mismo vocabulario cambia de escenario, pero no de lógica.

En la industria, estos términos describen líneas de producción, bandas transportadoras y supervisión centralizada mediante SCADA. En el hogar, la misma lógica controla iluminación y climatización. En la agricultura, un sensor de humedad y una consigna deciden cuándo regar. En servicios, un lazo de control gestiona el acceso a un edificio o el monitoreo ambiental de un espacio.

Conclusión: comprender sensores, actuadores, controladores, el concepto de lazo de control y las formas básicas de conectividad constituye la base para abordar cualquier proyecto de automatización, sin importar el escenario.
