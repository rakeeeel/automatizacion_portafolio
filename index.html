02 — FUNDAMENTOS

Qué es automatizar un proceso

Automatizar es transferir a un sistema técnico las tareas de medir, decidir y actuar que antes hacía una persona, para que un proceso se ejecute con menos intervención manual, de forma más repetible y segura.

En un entorno industrial esto se aplica a líneas de producción, bandas transportadoras, hornos o brazos robóticos. En un entorno de servicios se aplica a edificios inteligentes, riego, control de acceso o monitoreo ambiental: el mismo principio de medir–decidir–actuar cambia de escenario, no de lógica.

Todo sistema automatizado se apoya en un lazo de control: un sensor mide una variable del proceso, un controlador compara esa medición contra un valor deseado (consigna) y un actuador corrige la diferencia. Cuando la salida del proceso se vuelve a medir y se usa para ajustar la siguiente acción, se dice que el lazo está cerrado o que tiene realimentación.

04 — ENTORNO PRÁCTICO

Arduino e Internet de las cosas

El puente entre la teoría del lazo de control y un prototipo funcional sobre la mesa de trabajo.

Hardware

  • Arduino UNO, Nano y Mega
  • ESP32 / ESP8266 con Wi‑Fi integrado
  • Sensores: DHT22, ultrasónico, LDR, PIR
  • Actuadores: servos, relés, motores DC

Software

  • Arduino IDE, lenguaje C/C++ simplificado
  • Funciones base: setup() y loop()
  • Librerías de sensores y comunicación
  • Monitor serie para depuración

Protocolos IoT

  • Wi‑Fi y Bluetooth para enlaces cortos
  • MQTT para publicar/suscribir datos
  • HTTP/REST para integraciones web
  • LoRa para largo alcance y bajo consumo

Plataformas en la nube

  • Node-RED para flujos visuales
  • ThingSpeak para graficar variables
  • Blynk / Home Assistant para dashboards
  • Bases de datos en tiempo real
