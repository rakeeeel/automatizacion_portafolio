01 — PROTOTIPADO

Arduino en la automatización

Cómo un microcontrolador de bajo costo permite construir un lazo de control real.

Arduino es una plataforma electrónica de código abierto formada por una placa con entradas y salidas, y un entorno de programación simplificado en C/C++. Facilita la creación de proyectos de automatización porque permite programar la placa para leer sensores y, con esa información, controlar componentes electrónicos.

El programa que corre en la placa se organiza en dos funciones básicas: setup(), que se ejecuta una sola vez al encender el sistema para configurar pines y comunicación, y loop(), que se repite de forma continua y contiene la lógica del lazo de control.

01

🌡️ Sensor

Detecta una condición física del entorno y la convierte en una señal legible.

02

🧠 Arduino

Lee la señal, la procesa y decide qué hacer según la lógica programada.

03

⚙️ Actuador

Ejecuta físicamente la acción: enciende, mueve, abre o cierra algo.

04

📊 Resultado

El proceso cambia y, si el lazo es cerrado, esa nueva lectura vuelve a evaluarse.

EJEMPLO · LAZO CERRADO SIMPLE CON UN SENSOR DE TEMPERATURA 
// Enciende un ventilador (relé) si la temperatura supera la consigna
const int pinSensor = A0;
const int pinActuador = 7;
const float consigna = 28.0; // °C

void setup() {
  pinMode(pinActuador, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  float lectura = leerTemperatura(pinSensor);

  if (lectura > consigna) {
    digitalWrite(pinActuador, HIGH);
  } else {
    digitalWrite(pinActuador, LOW);
  }

  Serial.println(lectura);
  delay(1000);
}
02 — CONECTIVIDAD

Internet de las Cosas (IoT)

El paso de un prototipo aislado a un sistema que puede monitorearse y controlarse a distancia.

El Internet de las Cosas permite que objetos y dispositivos físicos se conecten a una red para compartir información. En un sistema de automatización, esto facilita el monitoreo remoto de variables, el almacenamiento histórico de datos y el control de dispositivos desde cualquier lugar con conexión.

Un ejemplo típico: un sensor de temperatura entrega datos a un microcontrolador, que los procesa y, mediante Wi‑Fi o Bluetooth, los envía a una plataforma en la nube para visualizarlos en tiempo real. Si se cumple una condición, el sistema también puede activar un actuador automáticamente o enviar una alerta.

Hardware

  • Arduino UNO, Nano y Mega
  • ESP32 / ESP8266 con Wi‑Fi integrado
  • Sensores: DHT22, ultrasónico, LDR, PIR
  • Actuadores: servos, relés, motores DC

Software

  • Arduino IDE, lenguaje C/C++ simplificado
  • Funciones base: setup() y loop()
  • Librerías de sensores y comunicación
  • Monitor serie para depuración

Protocolos IoT

  • Wi‑Fi y Bluetooth para enlaces cortos
  • MQTT para publicar/suscribir datos
  • HTTP/REST para integraciones web
  • LoRa para largo alcance y bajo consumo

Plataformas en la nube

  • Node-RED para flujos visuales
  • ThingSpeak para graficar variables
  • Blynk / Home Assistant para dashboards
  • Bases de datos en tiempo real
Arduino + IoT: Arduino aporta la interacción directa con sensores y actuadores; el módulo de conectividad (por ejemplo un ESP32 con Wi‑Fi integrado) aporta el puente hacia la plataforma en la nube, cerrando el lazo entre el mundo físico y el digital.
03 — COMPARATIVA

Cómo elegir un protocolo de comunicación

Cada protocolo resuelve un problema distinto: alcance, consumo, velocidad o simplicidad.

Protocolo Alcance Consumo Uso típico
Wi‑Fi Corto/medio (red local) Medio–alto Enviar datos directo a la nube desde un ESP32.
Bluetooth Corto (unos metros) Bajo Configurar el dispositivo o enlazarlo a un celular.
MQTT Depende de la red base Bajo (mensajes ligeros) Publicar lecturas de sensores de forma eficiente.
LoRa Largo (varios km) Muy bajo Sensores remotos en agricultura o zonas sin Wi‑Fi.
04 — APLICACIONES

Qué se puede construir con Arduino e IoT

Ejemplos concretos donde ambos se combinan para automatizar un proceso real.

🌱 AGRICULTURA

Riego inteligente

Un sensor de humedad de suelo decide, junto con Arduino, cuándo activar una electroválvula, y reporta el estado por Wi‑Fi.

🏠 HOGAR

Monitoreo ambiental

Un DHT22 publica temperatura y humedad por MQTT a un panel accesible desde el teléfono en tiempo real.

🏢 SERVICIOS

Control de acceso

Un lector RFID conectado a Arduino valida tarjetas y registra cada evento en una base de datos remota.

🏭 INDUSTRIA

Supervisión de línea

Sensores infrarrojos cuentan piezas en una banda transportadora y envían el conteo a un dashboard en la nube.
